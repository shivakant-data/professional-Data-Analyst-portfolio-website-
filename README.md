# Shivakant — Data Analyst Portfolio

Responsive static portfolio website showcasing Python, Pandas, Advanced SQL, Power BI, Excel and six completed analytics projects.

## Files
- `index.html` — portfolio content
- `styles.css` — responsive design
- `script.js` — mobile navigation and footer year
- `netlify.toml` — Netlify publish configuration

## Deploy
Push the folder to GitHub, then import the repository into Netlify. Leave the build command blank and use `.` as the publish directory.

## Customize
Replace the LinkedIn placeholder URL in `index.html` with the final public profile URL. A professional headshot can also be added later.
